02 / INVENTORY CONTROL
Reservations move from client intent to database authority.
01
Query live ticket types
Prices, limits, and available quantity come from Supabase catalog data.
02
Call the reservation RPC
The database validates availability and calculates the order values.
03
Lock with idempotency
Repeated requests do not create duplicate reservations.
04
Expire or cancel safely
Lifecycle functions release inventory without trusting client timers.
